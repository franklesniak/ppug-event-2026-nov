# Reconstructed Prompt: Fill the Gaps From Community Style Guides

Here is my PowerShell style guide. Compare it with these community PowerShell style guides: the PoshCode PowerShell Practice and Style guide, and Microsoft's Strongly Encouraged Development Guidelines.

Find guidance that the community guides cover and my guide doesn't mention at all. Ignore every topic where my guide already takes a position, even if a community guide disagrees with it.

Add the missing guidance to my style guide, in my guide's structure and voice, without changing any rule that is already there. List each addition and the source it came from.
